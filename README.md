# MOVIEREC – Kollywood Movie Intelligence

An explainable hybrid movie recommendation system for 120 Tamil films
(2007–2026), built with R and Shiny.

## Team
- A. Akash (24MID0284)
- R. Giridharan(24mid0012)

## How to run
1. Install R and RStudio.
2. Open `Movie Reg App/app.R` in RStudio.
3. Click **Run App**.

## Features
- Hybrid recommendation (content + collaborative, adjustable weight)
- Explainable scores, mood discovery, compare movies, analytics
